openssl x509 -in progist-home-ca.crt -noout -fingerprint -sha256

Результат должен совпасть с SHA-256 выше.

2. Установите

  1. Откройте эту страницу в Safari и нажмите «Профиль для iPhone / iPad / Mac».
  2. Разрешите загрузку профиля конфигурации.
  3. Настройки → Профиль загружен (вверху) → Установить, введите код-пароль.
  4. Настройки → Основные → Об этом устройстве → Доверие сертификатов — включите переключатель для «Progist Home Private Network».

Без последнего шага сертификат установлен, но не считается доверенным.

  1. Скачайте Сертификат (.crt) (кнопка выше) и дважды щёлкните по файлу. Откроется «Связка ключей».
  2. В окне выбора связки оставьте Вход и нажмите «Добавить» (для всех пользователей Mac выберите Система).
  3. В «Связке ключей» откройте раздел «Сертификаты» и найдите Progist Home Root CA: на нём будет красный значок «не является доверенным».
  4. Дважды щёлкните по сертификату и раскройте блок Доверие. В пункте «При использовании этого сертификата» выберите Всегда доверять.
  5. Закройте окно и введите пароль от Mac. Значок сменится на синий «плюс»; перезапустите Safari.

Шаг 4 обязателен. Начиная с macOS 13, сертификат, добавленный в связку или установленный профилем, не считается доверенным для сайтов, пока вы не выбрали «Всегда доверять» вручную. Поэтому для macOS мы рекомендуем .crt, а не профиль.

Или одной командой в Терминале (потребуется пароль администратора):

sudo security add-trusted-cert -d -r trustRoot -k /Library/Keychains/System.keychain ~/Downloads/progist-home-ca.crt

PowerShell (от имени пользователя, появится окно подтверждения):

Import-Certificate -FilePath "$env:USERPROFILE\Downloads\progist-home-ca.crt" -CertStoreLocation Cert:\CurrentUser\Root

Вручную: дважды щёлкните .crt → Установить сертификат → «Поместить все сертификаты в следующее хранилище» → Доверенные корневые центры сертификации.

Для всех пользователей компьютера используйте Cert:\LocalMachine\Root в PowerShell от администратора.

  1. Скачайте .crt.
  2. Настройки → Безопасность (или «Биометрия и безопасность») → Шифрование и учётные данные → Установить сертификат → Сертификат ЦС.
  3. Подтвердите предупреждение и выберите файл.

Chrome доверяет пользовательским сертификатам. Многие сторонние приложения (Android 7+) их игнорируют: это ограничение системы.

Debian / Ubuntu:

sudo cp progist-home-ca.crt /usr/local/share/ca-certificates/progist-home-ca.crt
sudo update-ca-certificates

Fedora / RHEL:

sudo cp progist-home-ca.crt /etc/pki/ca-trust/source/anchors/
sudo update-ca-trust

Arch:

sudo trust anchor --store progist-home-ca.crt

Chrome / Chromium используют собственную базу NSS:

certutil -d sql:$HOME/.pki/nssdb -A -t "C,," -n progist-home -i progist-home-ca.crt
  1. Настройки → Приватность и защита → Сертификаты → Просмотр сертификатов.
  2. Вкладка Центры сертификации → Импортировать…, выберите .crt.
  3. Отметьте «Доверять при идентификации веб-сайтов».

Вместо импорта можно включить security.enterprise_roots.enabled в about:config: Firefox начнёт использовать системное хранилище.
