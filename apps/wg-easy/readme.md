ens3 → нодовский внешний интерфейс
можно без hostNetwork, но тогда не будет доступа из домашней сети к клиентам.

Client-to-client (hairpin) между VPN-клиентами по умолчанию запрещён последним правилом `wg0 -o wg0 -j DROP`.
Точечные ACCEPT-правила пробрасывают конкретные пары/подсети (least privilege) — сейчас разрешено:
- beget (10.8.0.2) → keenetic-yolki (10.8.0.10) и его LAN 10.3.0.0/24 (k3s-yolki node) — нужно было для доступа beget к yolki-proxy/k3s-yolki.
Дальнейшие пары добавлять по той же схеме: `iptables -A FORWARD -i wg0 -s <src>/32 -d <dst> -j ACCEPT` перед финальным DROP.
